# IDD-0010.spec-settings-window-navigation

## Intent

ParakeetDrop separates frequent transcription from occasional configuration. The main window is for transcription; the application menu opens a separate searchable Settings window with left navigation and a right detail pane.

## Related Specifications

- IDD-0001 — Local desktop transcription
- IDD-0003 — Model settings and availability
- IDD-0004 — Compact visual system
- IDD-0007 — AI transcript post-processing
- IDD-0009 — Push-to-Talk dictation

## Behavior

- The main window has no Models or AI top-level tabs and always opens on the Transcribe workspace.
- **Settings…** in the application menu opens a separate nonmodal desktop window. Opening Settings repeatedly activates the existing window rather than creating duplicates. It may be closed and reopened independently of an active transcription.
- A text search sits above a persistent left sidebar. Four sections appear: Recognition, Models & storage, Dictation, and AI post-processing. The right pane shows only the active section.
- Search is case-insensitive, matches section names and recognizable individual setting names or aliases, and selects the first matching section. Nonmatching sidebar items remain visible and clickable but are visually dimmed; clearing the query restores normal contrast. An unmatched query preserves the existing selection.
- Recognition configures the supported Parakeet model, device, and CPU threads; Models & storage configures the models folder, installed-model inventory, explicit download, delete, and disk usage; Dictation configures Windows Push-to-Talk; AI post-processing configures enablement, provider, model, endpoint, instructions, and connection.
- The main workspace retains a compact model name and availability indication plus a direct download shortcut only when the model is unavailable. Model selection itself is no longer a routine workspace control.
- Settings edits retain atomic persistence and normalization. Running transcription or AI operations retain immutable snapshots captured at operation start. The settings window does not interrupt either.
- Downloads remain explicit, cancellable, and modal to the window initiating them. Deletions require confirmation, and AI API keys are session-only.
- Settings keeps ParakeetDrop's compact dark desktop visual system on Windows and macOS.

## Non-Goals

- No new recognition models, recognition engine, AI capability, theme editor, global settings shortcut, or Apply/Cancel transaction is introduced.
- Search never hides or disables categories.

## Acceptance Criteria

- The primary window has no Models/AI tabs and retains its file queue, transcription actions, raw transcript previews, copy actions, and manual AI improvement.
- Settings opens from the application menu in its own window. Reopening focuses the same window and preserves the current user settings.
- Model selection, processing device, CPU threads, model folder, inventory, model download/deletion, Windows dictation, and AI configuration are available in their appropriate Settings section.
- Searches such as GPU, threads, download, shortcut, Ollama, and API key select the expected section while leaving other section names visible but dimmed.
- The main workspace immediately reflects a model downloaded, removed, or made unavailable through Settings; a missing model can be downloaded directly from the main workspace.

## Verification

- Unit tests exercise setting-name search, nonmatching result behavior, and navigation-section ordering.
- Windows and macOS desktop UI checks exercise opening/reopening the settings window, section switches, search, direct missing-model download, model deletion confirmations, and responsiveness of ongoing transcription.
- Existing tests continue to cover atomic settings persistence, model lifecycle, and immutable transcription and AI execution snapshots.
