# IDD-0008.adr-parakeet-ultra-native-runtime

## Context

ParakeetDrop requires offline transcription of supported audio and video files, including long recordings and multilingual speech. The previous Whisper-specific decoder controls and recovery behavior do not define the behavior of the selected Parakeet model and are not carried into the new recognition architecture.

The product decision selects [Moondream Parakeet Ultra Q8_0 in GGUF format](https://huggingface.co/handy-computer/parakeet-ultra-gguf), running locally through the [`handy-computer/transcribe.cpp` native C API](https://github.com/handy-computer/transcribe.cpp) called from the .NET application. The model contract is source-language transcription with automatic language detection, no ASR translation, and long-form processing without an application-level second VAD or arbitrary overlapping segmentation.

## Decision

- Ship one supported recognition model, `parakeet-ultra-Q8_0.gguf`. Its upstream revision, download URL, exact byte size, and SHA-256 are pinned to the published artifact and verified against downloaded bytes.
- Call the native C API in-process from the .NET application. Keep the native library, backends, and dependent runtime files app-local on macOS ARM64 and Windows x64; do not require a command-line recognizer, Python, or a separately installed SDK/runtime. The current public distribution packages macOS ARM64 only.
- Supported native-runtime targets are macOS Apple Silicon (ARM64) and Windows x64. CPU recognition is available on both. Auto selects Metal on supported Apple Silicon or Vulkan on supported Windows hardware, falling back to CPU when the preferred backend is unavailable. A forced GPU request reports an actionable failure when that platform's GPU backend is unavailable. macOS x64 is excluded, with no Rosetta compatibility requirement.
- Treat the model as non-streaming. Use its native long-form recognition behavior on the prepared audio. Do not promise partial segment previews or invent progress percentages when the native call supplies no accurate progress.
- Preserve the full raw result and available source-ordered segments. Display a detected language only when returned. Do not manufacture Whisper confidence, entropy, or other unsupported probability values; unsupported recognition probabilities are `null`.
- Keep optional AI transcript correction governed by IDD-0007. It receives transcript text and supported metadata only after a complete successful recognition result; AI does not receive audio or file paths.
- Use a new ParakeetDrop application identity and data location. Earlier WhisperDrop settings, models, application identities, Casks, and updater paths are not migrated, discovered, or removed automatically.
- The current replacement runtime is not shipped in a public release until the macOS ARM64 CPU and Metal paths have been exercised on Apple Silicon and the observed upstream/model revisions, ABI, device, results, and diagnostics are recorded in the repository. A package containing backend files alone is not proof that Metal inference works. Windows runtime support is separately verified with an actual local-model CPU transcription; Vulkan support is claimed only after a run reports the Vulkan backend. Intel macOS is excluded.

## Alternatives Considered

- Keep Whisper.net and its Whisper-specific decoder controls: rejected because the selected product model and result contract are different.
- Launch a recognizer CLI or use Python at runtime: rejected because recognition must remain in-process and the installed application must not require those tools.
- Add Parakeet V3, multiple quantizations, or an application-level streaming/overlap pipeline: rejected for the first product version.

## Consequences

The native header, ABI layout, library build, model artifact, backend packaging, and actual CPU/GPU behavior must be pinned and verified for every supported runtime. Technical measurements and tested-device evidence belong in the implementation's spike report; this decision does not claim that untested hardware paths have passed.
