# IDD-0001.spec-local-desktop-transcription

## Intent

WhisperDrop is a deliberately minimal desktop application for transcribing audio files locally. Its central promise is: "Transcription runs locally. Your audio never leaves this device."

## Related Specifications

- IDD-0002 — Transcription workspace
- IDD-0003 — Model settings and availability

## Behavior

- The application supports Windows and macOS, with release targets of Windows x64 and macOS ARM64. Additional Uno- and runtime-supported targets may be included when they require no separate MVP architecture.
- The main window provides Transcribe and Settings tabs. It opens on Transcribe only when transcription is available; when the selected model is not downloaded or transcription cannot otherwise be used, it opens on Settings.
- The interface continuously communicates that transcription is local and does not imply cloud or API processing.
- Audio, transcripts, file names, paths, and file metadata are never sent to an external service. The only network operation associated with recognition is user-initiated download of the selected Whisper model.
- Once a model is downloaded, recognition works offline.
- The distributed application is self-contained: users do not manually install FFmpeg, Python, whisper.cpp, command-line utilities, codecs, native runtimes, or other dependencies. Components shipped with the application distribution are allowed.
- File lists, transcription results, and recognition history are session data. They are discarded when the application closes and no transcript files are created automatically.

## Product-Significant Architecture And Constraints

- The product must package all prerequisites needed for its supported transcription formats and supported platforms.
- Release builds require verification on clean Windows and macOS machines.

## Non-Goals

- Microphone recording, transcription history, automatic text-file saving, transcript editing, cloud recognition, OpenAI API use, translation, summarization, diarization, subtitle editing, SRT/VTT export, and parallel transcription are outside the MVP.
- The application does not automatically download a model.

## Acceptance Criteria

- A user can launch the application on each required platform and immediately see an empty Transcribe workspace when transcription is available, or Settings with model guidance when it is unavailable.
- After a model has been downloaded, the user can transcribe without a network connection.
- Closing and reopening the application leaves the transcription workspace empty while retaining the user's settings and downloaded models.
- The application does not require a separately installed media or Whisper prerequisite.

## Verification

- Platform release verification establishes that the application launches and can perform supported offline transcription on clean Windows and macOS environments.
- Privacy review establishes that recognition content and file metadata have no external transmission path and that model download occurs only after explicit user action.
- Session-lifecycle coverage establishes that transcription workspace data is not restored after a new launch.
