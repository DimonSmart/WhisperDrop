# ENG-0002.rule-whisper-local-runtime

## Rule

Use Whisper.net 1.9.1 or later with the native runtime packaged by WhisperDrop. Configure process-global runtime selection exactly once before the first `WhisperFactory`, reuse the recognition model factory, and create processors from immutable recognition-option snapshots.

## Applicability

Conditional

## Applies when

- implementing or changing local transcription, Whisper-model management, runtime packaging, or recognition execution

## Rationale

Whisper.net's native library choice becomes process-global when the first Whisper/VAD factory touches the runtime. Treating device selection as an ordinary processor option would create misleading hot-switch behavior. Factory reuse avoids reloading large recognition models.

## Guidance

- Configure `RuntimeOptions` only in the runtime-selector responsibility and only before first native initialization. Do not reset `LoadedLibrary`, force-reload a DLL/dylib, or claim that disposing `WhisperFactory` changes native runtime.
- `Auto` considers only backends actually shipped by WhisperDrop. CPU remains the mandatory fallback.
- `CPU` uses the bundled portable runtime with `WhisperFactoryOptions.UseGpu = false`.
- `GPU` is exposed only through supported packaged acceleration. With the current package set, the supported macOS ARM64 target can use the bundled Metal backend and its packaged `ggml-metal.metal` resource; unsupported systems receive a user-facing availability error.
- Keep the loaded model factory, but create a new processor per primary or local Beam Search run. Observe native segment callbacks and request native abort on detected consecutive repetitions, while distinguishing internal cancellation from user cancellation. Await native processor disposal before creating the next run. Decode the prepared 16 kHz mono WAV once and pass remaining sample slices, keeping timestamp offsets in the application. Limit local Beam repair windows to 45 seconds and at most five repair attempts before switching the remaining suffix to Beam. Never retry the whole transcript merely because a loop occurred. Hardcode entropy 1.8 and log-probability -0.8, per IDD-0008. Apply language detection, translation, prompt, thread count, and native progress callback at processor-builder level.
- Auto language uses `WithLanguageDetection()`; do not pass the literal `"auto"` through `WithLanguage(...)`.
- Package required runtime components with the application rather than requiring Python, whisper.cpp, a command-line executable, or manually downloaded native libraries.
- Preserve build/publish verification for the package's `build/win-*` and `build/macos-*` native layout when updating Whisper.net.

## Verification

Tests cover settings snapshots, restart-required semantics, batch consistency, repeated-phrase detection, sample offsets, and local-repair resume logic, and model/factory lifecycle where practical. Local opt-in integration tests exercise the real Whisper recognizer. Build/publish must fail clearly if mandatory bundled runtime files are no longer present at the expected package paths.
