# ENG-0001.rule-desktop-application-foundation

## Rule

Implement WhisperDrop as a .NET 10 Uno Platform desktop application using Skia Desktop, with standard dependency-injection and hosting composition. Keep the application architecture proportionate to its small scope and use one production application project plus one test project unless an additional project provides clear practical value.

## Applicability

Always

## Rationale

The chosen desktop foundation provides the required cross-platform product surface while a simple composition model avoids an unnecessary multilayer architecture.

## Guidance

- Use existing Uno desktop and user-interface patterns as reference material, without importing unrelated architectural complexity.

## Verification

Project configuration and application composition demonstrate .NET 10, Uno Platform, Skia Desktop, and standard dependency-injection and hosting use. The solution keeps one production application project and one test project unless a documented practical need justifies an additional project.
